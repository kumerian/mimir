# Document the initial Agile process

**Status:** Done

**User story:** As a team member, I want a high-level description of the current Agile process, including an initial Definition of Done, so the team has a shared starting point.

**Scope:** Describe the current process at a high level. The Scrum Master will detail the process and Definition of Done.

**Acceptance criteria:**

- [x] A folder within the /docs folder that will contain all documents pertaining to the agile process
- [x] A first setup of the most common documents used in an Agile software development process
  - [x] Definition of Ready
  - [x] Definition of Done
  - [x] Definition of Undone
  - [x] Any other document the Scrum Master deems useful

**Verification:** Documentation-only change; application tests and the runtime criterion do not apply. Verified the Agile documents and their internal links.
